## Sepuluh Invarian (A1–A10)

### A1 — Reality Before Content
Setiap halaman mesti menjawab *"realiti apa yang ini wakili?"*, bukan sekadar *"kandungan apa yang ini paparkan?"*

### A2 — Authority Explicit
Setiap keupayaan mendedahkan `owner · authority · mutation_rights · governance`. Ejen tidak meneka kuasa.

### A3 — Capability Explicit
Setiap permukaan mengisytiharkan **apa yang boleh** dan **apa yang tidak boleh** dilakukannya.

### A4 — State Is First Class
Ejen menerima `{state, confidence, last_verified, receipt}` — bukan dokumen.

### A5 — Discovery Is Traversable
Dari satu titik masuk (`/discovery/index.json`), ejen menemui identiti · autoriti · keupayaan · keadaan · tadbiran · (akan datang: model dunia) tanpa carian manual.

### A6 — Receipts Over Claims
Tuntutan tanpa resit = UNKNOWN. `Reality > Documentation`.

### A7 — One Reality, One Canonical Declaration
Tiada konflik kanonikal serentak (7 lawan 8 kata kerja dsb.). Satu realiti, satu pengisytiharan.

### A8 — Agent Must Learn Without Human
Ujian wajib: *buang Arif — bolehkah ejen faham federasi?* Tidak = GAGAL. Ini KPI sebenar.

### A9 — Humans First
Permukaan ejen tidak mengorbankan manusia. Setiap model ada Human View + Agent View.

### A10 — Reality Freshness
Semua keadaan membawa `age · freshness · trust · source`.
