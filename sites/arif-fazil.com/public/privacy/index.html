Privacy

This is a personal site. It has no accounts, no advertising, and no tracking of what you read.

What is collected

Nothing you read is tracked. No login, no newsletter form, no cross-site analytics. Cloudflare sets one security cookie (cf_clearance) to tell humans apart from bots — not used for advertising. No other cookies; nothing written to browser storage.

Third parties

Typefaces load from Google Fonts and Fontshare. No analytics script and no visitor counter run on this site today — if a cookieless counter is ever enabled, this page changes before it does. No personal profile is built from any of it.

If you email

A message arrives in an ordinary mailbox and stays there. Your address is not added to a list, sold, or shared. Ask and it is deleted.

Agent and machine surfaces

Public files such as surfaces.json, llms.txt and the /.well-known directory exist so software can discover what this site publishes. They contain no visitor data.
