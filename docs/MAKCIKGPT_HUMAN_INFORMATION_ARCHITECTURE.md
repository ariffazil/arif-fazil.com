## 2. Attention Preservation Rules

1. **Card Scannability under 3 Seconds:**  
   Every card displays: Series tag, Date, Title, One-line dek (if present), and Destination link.
2. **Strict Color Discipline:**  
   - Base: Charcoal / Dark Slate (`#0A0B0D` / `#11151C`).
   - Yellow (`#D9A62E`): Attention / Open civic question / Lead accent.
   - Red (`#E0301E`): Active contradiction / Public risk / Dispute.
   - Green (`#31C48D`): Sealed revision / Passed gate.
   - Avoid decorative coloring on metadata tags.
