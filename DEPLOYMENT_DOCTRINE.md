## DEPLOYMENT PIPELINE

```
make verify → make sync-aaa → make build → make verify-pages → make reload
```

### Step-by-step:

1. **`make verify`** — Pre-deploy verification gates
   - `verify-surfaces.cjs` — Checks all surfaces.json entries against live HTTP
   - `verify-pages.sh` — Curls every dist/ page, asserts 200
   - `verify-content.sh` — Checks content assertions (SPA-aware for React pages)
   - `verify-content-gates.py` — Content authority checks (G1 receipt, G2 epistemic)
   - `caddy validate` — Validates Caddy config
   - Dev-only entry point scan — Ensures no `/src/` or `/@vite/` in dist/

2. **`make sync-aaa`** — Syncs AAA dist/ into arif-fazil.com dist/aaa/

3. **`make build`** — Builds the React SPA
   - `npm run build` — Vite build
   - `render-propa.cjs` — Renders propa page
   - `inject-institutional-panel.py` — Injects WEALTH panel
   - `generate-discovery.cjs` — Regenerates sitemap, llms.txt, surfaces.json

4. **`make verify-pages`** — Page inventory gate
   - Scans every dist/*/index.html
   - Curls live URL
   - Asserts 200

5. **`make reload`** — Validates + reloads Caddy
   - `caddy validate` — Final config check
   - `systemctl reload caddy` — Applies config

## COMMON FAILURE MODES

### 1. surfaces.json mismatch
**Symptom:** `make verify` fails with "Fail-closed: build blocked"
**Fix:** Update `surfaces.json` to match live HTTP reality
**Rule:** If Caddy redirects (308), surfaces.json must say `"status": "redirect"`

### 2. SPA content assertions fail
**Symptom:** `verify-content.sh` reports "MISSING" for SPA pages
**Fix:** Content is in JS bundle, not HTML. Use `assert_present_spa` function.
**Rule:** SPA pages need SPA-aware assertions that check JS bundles.

### 3. New file not served by Caddy
**Symptom:** File exists in dist/ but returns 404
**Fix:** Add path to `@static_dirs` in Caddyfile
**Rule:** Every new static file path must be in the `@static_dirs` path list

### 4. Build fails on missing directory
**Symptom:** `FileNotFoundError: [Errno 2] No such file or directory`
**Fix:** Ensure directory exists before build, or update Makefile paths
**Rule:** When paths change (e.g., `/propa/` → `/world/propa/`), update ALL references
